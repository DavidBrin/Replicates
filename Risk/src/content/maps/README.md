# Maps — provenance and licences

Sixteen boards, each one JSON file with its territory outlines inline (D36),
regenerated by `pnpm run build:maps` and **committed** so a graph change shows up
in a diff. Loaded one at a time through `index.ts`'s per-slug dynamic import, so
the initial bundle never carries a board it is not showing (D40).

## The rule everything here follows

**Facts are free; artwork is not** (D1). Territory names, adjacency graphs,
territory counts and continent bonus values are facts about a published game and
are reused freely. No SMG map artwork is shipped, and neither is the Wikimedia
"Risk board" SVG family — `Risk_board.svg`'s own source metadata reads *"Own work
by uploader — based on a Risk board i own"*, so its CC BY-SA tag cannot license
board art the uploader never held rights to, and `Risk_game_board.svg` inherits
the same defect (D38). ShareAlike sources (the Wikimedia adjacency *graph*, the
GeoDataSource country-borders CSV) are used only as test oracles, never shipped.
GPL/AGPL projects were read for ideas and never copied.

RISK is a trademark of Hasbro. This is a non-commercial portfolio replica of
SMG Studio's *RISK: Global Domination* containing no copied Hasbro or SMG assets
(D1).

Edge counts are **after `loadMap` unions the sea links in** (F45): Classic is 74
land borders plus 9 sea lanes, not 83 land borders.

Classic's graph and its geometry come from different files on purpose.
`sonesson89/TotalRisk` drew the only permissively licensed Classic board, and its
*graph* carries two bugs — a spurious `northwest_territory–quebec` and a missing
`new_guinea–western_australia`. Seven independent sources agree exactly on the
corrected graph, which is what the canonical file holds. World Extended is built
on the same TotalRisk base, so both corrections are applied to it too; its edge
count is unchanged at 94 because one edge goes and one arrives.

Napoleonic Europe's territory ids are re-minted from the display names: eight of
the source's own slugs are mangled (`galicia_le_n` for "Galicia & León",
`le_de_france` for "Île-de-France"). World Extended's "New Zeeland" is corrected
to "New Zealand".

Territory and continent counts are tuned to the published counts in
`research/map-data/smg-catalogue/all-maps.json` so the boards feel like the
originals without copying one; the blizzard and portal counts are the
catalogue's where it has an entry. **All names on these boards are ours**:
territories are named after their largest source countries ("Guinea & Senegal")
or by compass band within their continent ("North West Africa"), and continents
are named by compass band. Where one of those coincides with a real region name,
that is because compass directions are compass directions.

Adjacency is **derived topologically** from shared polygon borders, never
hand-typed — verified against `topojson.neighbors` over all 177 world countries
at 313 of 314 edges with zero false positives. Continent bonuses come from
`bonus ≈ round(size / 3 + borders / 2)`, which reproduces Classic's own
5 / 2 / 5 / 3 / 7 / 2 to within one. **Sea links are hand-authored** — geometry
cannot tell you about a shipping lane — from the pipeline's own report of which
territories a board leaves unreachable; `pnpm run build:maps --suggest` reprints
it.

| `tiny4.json` | 4 / 1 / 6 | `research/map-data/preeminence/tiny4.json` | as above |
| `mini.json` | 6 / 2 / 7 | `research/map-data/preeminence/mini.json` | as above |
| `quad.json` | 20 / 4 / 26 | `research/map-data/preeminence/quad.json` | as above |

Preeminence ships no coordinates and no bonus values, so the geometry is a
schematic grid and the bonuses come from the same heuristic the generated boards
use. These four are small enough to reason about exhaustively in a unit test,
which is a different job from being a board worth playing: they are listed in
`FIXTURE_SLUGS` and **never appear in the in-game map picker** (D39).

## Random boards

`generateVoronoiMap(options, seed)` in `@/engine/map` mints a board at run time —
jittered hex grid, Delaunay triangulation, Voronoi dual, cells merged into
territories (D37 Tier 4). Nothing is persisted here; the output is **ours**, with
invented place names, and it is held to the same `validateMap` gate as every file
in this directory.

| considered | verdict |
|---|---|
| Wikimedia `Risk_board.svg`, `Risk_game_board.svg`, the board PNGs | traced from a retail Hasbro board; the CC BY-SA tag cannot grant what the uploader never held (D38) |

| `research/map-data/risk-neighborhood/` | MIT but three known graph errors |
| `research/map-data/preeminence/middle-earth.json` | graph is MIT, but the place names are Tolkien Estate IP and there is no geometry to draw it with — skipped (D39) |
| amCharts geodata, `djaiss/mapsicon`, simplemaps SVGs | linkware, no licence, or a redistribution clause |
